About

Welcome to the Notes Management System.

This application helps users to securely create, store, update, and manage their personal notes. Each user has their own private workspace where notes are stored safely in the database.

Built using Flask (Python) and MySQL, this system provides full CRUD functionality with user authentication including login, registration, and password management.

The goal of this project is to simplify note-taking and improve productivity by keeping all notes organized in one place.
